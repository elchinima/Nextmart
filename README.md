## 🚀 About

**Nexmart** is a stylish and interactive storefront landing page focused on gaming products.  
It combines a clean layout with immersive UI details, motion effects, and responsive behavior for desktop and mobile.

## ✨ Highlights

- 🎯 Gooey animated navigation with particle transitions
- ❄️ Pixel snow effect in the hero section
- 🧩 Split-text reveal animation for headings
- 🃏 Tilted product cards with motion depth
- 💥 Click spark and border glow micro-interactions
- 🖼️ Infinite partner logo loop section
- 📱 Mobile-friendly layout with responsive tweaks
- 🔐 Animated neumorphic login modal

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (`style.css` + `responsive.css`)
- **Vanilla JavaScript (ES6+)**

## ▶️ Run Locally

No dependencies required.

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/Nexmart.git
   ```
2. Open the project folder.
3. Run `index.html` in your browser.

For best results, use a local server:

```bash
# VS Code Live Server
# or
python -m http.server 5500
```
